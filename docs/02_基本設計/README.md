## 画面一覧
5画面 + モーダル7つ。画面の切り替えは、トップページを起点にする(トップ → 各画面 → 「トップ」で戻る)。ゲームの状態は、画面を移っても残る。

| 画面 | 内容 |
|---|---|
| トップページ | ロゴ、「ようこそ、〇〇さん」、所持チップと所持金、ゲームスタート / クイズモード / チップを用意する(ボーナスを受け取れる日は「ボーナス」の札)/ 設定、「カードカウンティングってなに?」 |
| ゲーム画面 | ヘッダー(トップ・デッキ数・リセット・効果音)、カジノテーブル、所持チップ・メッセージ・解説ボタン・COUNT ボタン、操作ボタン |
| クイズ画面 | クイズの種類を選ぶ → 出題(進み具合、問題、選択肢)→ 正解・解説 → 結果(星、○×の一覧) |
| 設定画面 | プレイヤー(名前、ゲスト番号)/ ゲーム(デッキ数、CPU 人数、chance 表示、デッキ数のおすすめ)/ クイズ(問題数、速さ)/ サウンド |
| チップを用意する画面 | チップがなくなったときの案内、「とほほ…」(チップも所持金もなく、ボーナスも受け取り済み)、所持チップと所持金、ログインボーナス、チップ交換(注意書き、チップと所持金の数字、左右に分かれた横棒のスライダー、もどす・交換する)、ゲームへ、これまでの記録 |
| カウンティング説明モーダル | トップから開く(F-28)。5ページを ◀▶ と点でめくる。← → キーでも動く |
| チップ切れの案内モーダル | ゲーム画面で、チップがなくなったときに表示(F-13)。閉じるボタンはなく、別の画面へ移る |
| デッキ数おすすめモーダル | ゲーム画面を開いたとき、3デッキ以上なら表示(F-26) |
| 解説モーダル | ゲーム画面の「解説」から開く(F-22)。← → キーでもめくれる |
| COUNT モーダル | カウント状況(F-10)。閉じるボタン、背景クリック、Esc で閉じる |
| 説明モーダル | COUNT モーダルの (?) から開く(F-15)。Esc や背景クリックで、説明だけ閉じる |
| カード一覧モーダル | COUNT モーダルの「のこりのカードを一覧で見る(七並べ)」から開く(F-24)。縦にマーク4つ、横に 1〜13。下の行に数字ごとの残り合計と確率、その下に凡例。「もどる」、Esc、背景クリックで一覧だけ閉じる |

## ワイヤーフレーム(メイン画面)
```
┌ [トップ] ゲーム ──── [2デッキ★▼] [リセット] [🔊] ┐
│╭──────────────── テーブル(フェルト) ────────────────╮│
││[SHOE]           [ チップトレイ ]            [DISCARD]││
││                  ディーラーのカード                   ││
││            ⌒ BLACKJACK PAYS 3 TO 2 ⌒                ││
││            ⌒ INSURANCE PAYS 2 TO 1 ⌒                ││
││       Dealer must draw to 16 and stand on all 17s    ││
││  [CPU2]        自分のカード(結果は上に大きく)  [CPU1] ││
││                   ( ベット円 )                        ││
│ ╰───────────────────────────────────────────╯ │
│ 所持チップ 1,000     メッセージ            [COUNT]     │
│        (1)(5)(25)(100)(500)                           │
│        [CLEAR] [REBET] [DEAL]  ← 段階で切り替わる      │
└──────────────────────────────────────────┘
```

## 画面の状態遷移(フェーズ)
```
betting ─DEAL→ (アップカードA?) ─はい→ insurance ─選択→ ┐
                   └いいえ────────────────────────────┤
          ┌─ ディーラー or プレイヤーがBJ → roundOver   │
          └─ playerTurn ─全ハンド終了→ dealerTurn → roundOver
roundOver ─NEXT / チップ / REBET&DEAL→ betting(75%超ならここでシャッフル)
```
| フェーズ | 操作ボタン |
|---|---|
| betting | チップ、CLEAR、REBET、DEAL、(チップ補充) |
| insurance | INSURANCE、NO |
| playerTurn | HIT、STAND、DOUBLE、SPLIT(条件を満たさないときは無効) |
| cpuTurn | なし(CPU が自動でプレイ) |
| dealerTurn | なし(自動) |
| roundOver | チップ、NEXT、REBET & DEAL |

COUNT ボタンとリセットは、どのフェーズでも押せる。デッキ数は betting / roundOver のときだけ変えられる。

## 外部連携
なし(ログイン、決済、メール、APIはすべてなし)。

## 総合テストの観点(07で使う)
- PC(1280px)とスマホ(390px)で、横スクロールなく全要素が見える
- 全フェーズの遷移を通しで操作できる。ラウンド中にリセットしても壊れない
- ディーラーの番の途中でリセットしても、古いラウンドのカードが出てこない
- 8デッキで多数ラウンド続けても、表示が遅くならない
- 通信を切っても、読み込み済みなら遊び続けられる(サーバー通信がないため)
