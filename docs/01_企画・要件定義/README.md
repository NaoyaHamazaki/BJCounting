# 01_企画・要件定義

## 書く内容
企画(ターゲット、提供価値、マネタイズ、予算、スケジュール)、機能要件、非機能要件、受入テストの観点。

## 状態
完了(最終更新:2026-11-16)。原典は `企画.txt`。2026-11-15 のQ&Aで決まったことを反映。

## 企画
- **ターゲット**:確率を楽しく学びたい人(小中学生の確率の勉強に近い位置づけ)。カジノでの利用を勧めるアプリではない
- **提供価値**:実際のプレイの中でカウントを練習でき、COUNT ボタンで答え合わせ(RC/TC、残り構成、確率)ができる
- **マネタイズ / 予算**:プロトタイプのため、なし。公開先は Railway(2026-11-15 オーナー指定)。料金はオーナーの Railway のプランによる(金額は未確認)
- **スケジュール**:未定(プロトタイプは 2026-11-15 に実装)

## 機能要件
| ID | 機能 | 内容 |
|---|---|---|
| F-01 | デッキ数の選択 | 設定画面で1〜8デッキを選ぶ。変えるとシャッフルし直す(ラウンド途中なら、そのラウンドを中止して賭けたチップを返す) |
| F-02 | リセット | シューとカウントを最初の状態に戻す。所持チップは変えない(ラウンドの途中なら賭けたチップを返す)。確認ダイアログあり(2026-11-16 変更) |
| F-03 | ベット | 色分けしたチップ(1/5/25/100/500)を置く。CLEAR、REBET(前回と同額) |
| F-04 | 配札 | プレイヤー2枚、ディーラー2枚(1枚は伏せる) |
| F-05 | プレイ操作 | HIT / STAND / DOUBLE / SPLIT |
| F-06 | インシュランス | ディーラーのアップカードが A のとき、ベットの半額で 2:1 |
| F-07 | ディーラーの自動進行 | S17。16以下で引き、17以上で止まる。カードは1枚ずつ間をあけて引く |
| F-08 | 精算 | 勝ち 1:1、ブラックジャック 3:2、引き分けは返金 |
| F-09 | シャッフル | シューの75%を配ったら、そのラウンドの後に自動でシャッフルし、カウントを0に戻す |
| F-10 | COUNT ボタン | 押すとモーダルで、RC、TC、出たカード(新しい順、各カードの +1/0/−1 つき)、残りカードの構成(小・中・大)、次に出る確率(カードの絵と%)を表示。**普段は表示しない**(練習のため)。子ども向けに、数値は最小限にする |
| F-11 | テーブル表現 | フェルトの扇形テーブル、アーチ状の印字(BLACKJACK PAYS 3 TO 2 / INSURANCE PAYS 2 TO 1)、ディーラールールの印字、チップトレイ、ベッティング・ボックス、チップのスタック |
| F-12 | シュー/トレイの連動 | シューの残量と、ディスカードトレイの量が、配った枚数に応じて増減する |
| F-13 | チップがなくなったとき | 所持チップが1未満になったら、少し待って(負けの演出を見せてから)「チップを用意する」画面へ移る。所持金もなく、今日のログインボーナスも受け取り済みなら「とほほ…」を表示し、クイズをすすめる(2026-11-16 変更。旧:+1,000 を補充) |
| F-14 | CPU プレイヤー | 0〜3人(初期2人)を同じテーブルに座らせる。CPU のカードもカウントの対象。行動は 右側の CPU → 自分 → 左側の CPU → ディーラー の順 |
| F-15 | 説明(?) | RC、TC、残りカードの構成、次に出る確率の横に (?) を置き、押すと説明をモーダルで表示 |
| F-16 | 勝敗の演出 | WIN / LOSE などを合計の数字の上に大きく表示。勝ちは光って弾け、負けは赤く揺れる |
| F-18 | チャンス表示 | 3パターン:TC +1 未満は非表示、+1 以上で「chance?」(青)、+2 以上で「chance!」(金・光る)を、専用アイコンつきで COUNT ボタンの上に表示。COUNT モーダルの先頭に、理由(TC、大きいカードの増え方、ブラックジャックになる確率とふだんとの比較、なぜ有利か)を目立たせて表示。テーブル上には出さない |
| F-19 | アイコン | 「21」のカードと「%」のチップを組み合わせたアプリアイコン(ブラウザのタブ、スマホのホーム画面、ヘッダー)。chance? / chance! 用のアイコン(カード + 右肩上がりの棒グラフ) |
| F-20 | トップページ | 「ゲームスタート」「クイズモード」「設定」の3つを選ぶ。教材であり、お金をかけた遊びをすすめるものではない旨を表示 |
| F-21 | 設定画面 | デッキ数、CPU の人数、chance 表示のオン/オフ、クイズの問題数(5/10/20)、カウントクイズの速さ(ゆっくり/ふつう/はやい)、効果音。ブラウザに保存 |
| F-22 | 解説モーダル | ゲーム画面の「解説」ボタンから開く。このラウンドで表になったカードを1枚ずつ ◀▶ でめくり、①出たカード(誰のカードか) ②点数付け ③残り枚数の変化 ④13ランクの確率の変化(引く前→引いた後、▲▼) ⑤RC・TC・チャンスへの反映 を表示。最後にまとめ(点数の足し算) |
| F-23 | クイズモード | 5種類:ぜんぶ / 点数(+1・0・−1) / カウント(1枚ずつ出るカードの合計) / 確率(次に出る確率、引いた後に上がるか下がるか) / トゥルーカウント。答えると、正解・不正解の演出と効果音、解説を表示。最後に星3段階の結果 |
| F-24 | カード一覧(七並べ) | COUNT モーダルのボタンから開く。まだ出ていないカードを、マーク(♠♥♦♣)ごとに 1(A)〜13(K) の順に並べる。出たカードは点線の空きマス。2デッキ以上は、各カードの右上に残り枚数を丸数字で出し、残りの割合で色分け(たくさん=緑 → 少ない=赤)。各数字の残り合計と次に出る確率、このラウンドで出たカードの金のわくも表示 |
| F-25 | ヘッダーのデッキ数 | ゲーム画面のヘッダーで、1〜8デッキを選べる(1・2 に ★)。設定画面と同じ値 |
| F-26 | デッキ数のおすすめ | 3デッキ以上でゲーム画面を開いたとき、「確率の学習には 1〜2デッキがおすすめ」を表示(A が1枚出たときの確率の変化を、1デッキと今のデッキ数で比べる)。「1デッキにする」「2デッキにする」「このまま」と、「次回以降表示しない」のチェック。設定画面で表示を戻せる |
| F-27 | チップを用意する | トップに所持チップと所持金を表示し、メニューから開く。画面には 所持チップ、所持金(単位なし)、ログインボーナス(1日1回、所持金 +20,000)、銀行口座(1チップ = 所持金 20。所持金→チップ、チップ→所持金の両方向。横棒スライダーと「半分」「ぜんぶ」)。はじめての人はチップ 1,000、所持金 0。ブラウザに保存 |
| F-28 | カードカウンティングの説明 | トップの「カードカウンティングってなに?」から開く。中学生向けの5ページ(①戻さないから確率が変わる ②点数をつけてたし算 ③プラスだとなぜ有利 ④残りの量でわる ⑤このアプリでの練習のしかた) |
| F-17 | 効果音 | カードを配る、チップを置く、シャッフル、勝ち・BJ・負け・引き分け。ヘッダーでオン/オフ(ブラウザに保存) |

### 要件の対象外(今回は作らない)
- 推奨ベット額の表示(2026-11-15 オーナー判断)
- 常時表示の練習モード、カウントの入力・正誤判定(COUNT ボタンで確認する方式に決定)
- サレンダー、複数席、ログイン、サーバーへのデータの保存(所持チップ・所持金・設定は、ブラウザにだけ保存する)

## 非機能要件
| 項目 | 内容 |
|---|---|
| 対応環境 | PC・スマホの最新ブラウザ(Chrome、Edge、Safari)。幅 360px〜 |
| 速度 | 8デッキ(416枚)でも、操作から表示まで体感の遅れがない |
| セキュリティ | サーバー・個人情報・外部通信なし。静的ファイルのみ |
| 運用コスト | Railway の料金(プランによる。未確認)。サーバー処理のない静的サイトなので、Serverless(アクセスがない間は停止)を使って料金を抑える(AI 提案。オーナーの承認待ち) |
| メール | 使わない(00_プロジェクト概要を参照) |

## 受入テストの観点(08で使う)
| ID | 合格の条件 |
|---|---|
| A-01 | 1〜8デッキを選べ、COUNT の残り枚数が 52×デッキ数 から始まる |
| A-02 | 1ラウンドを最後まで遊べる(ベット → 配札 → 操作 → ディーラー → 精算) |
| A-03 | ダブル、スプリット、インシュランスが、ルールどおりに精算される |
| A-04 | COUNT の RC が、出たカードの Hi-Lo の合計と一致する。伏せたカードは数えない |
| A-05 | TC = RC ÷ 残りデッキ数 になっている |
| A-06 | 確率 = 残り枚数 ÷ 見えていない枚数 × 100 で、合計が100%になる |
| A-07 | 75%を過ぎると、ラウンド後にシャッフルされ、カウントが0に戻る |
| A-08 | テーブルの見た目(扇形、印字、チップトレイ、シュー、トレイ、チップのスタック)が企画の意図どおり |
| A-09 | スマホで横スクロールなく遊べる |
| A-10 | CPU のカードも RC に含まれ、CPU の人数を変えられる |
| A-11 | (?) を押すと説明が表示され、閉じられる |
| A-13 | TC +1 未満では何も出ず、+1 以上で「chance?」、+2 以上で「chance!」が COUNT ボタン付近に出て、モーダルに理由が表示される |
| A-14 | トップページから3つの画面に移れ、各画面から「トップ」で戻れる |
| A-15 | 設定を変えるとゲームとクイズに反映され、ブラウザを開き直しても残っている |
| A-16 | 解説モーダルで、出たカードごとに5つのステップが正しい数字で表示される |
| A-17 | クイズの5種類が出題され、正解・解説・結果が表示される |
| A-18 | カード一覧で、出たカードの場所の枚数が減り(1デッキは空きマスになる)、丸数字の色が残り枚数に合っている。数字ごとの合計が COUNT の「のこり」と合う |
| A-19 | ゲーム画面のヘッダーでデッキ数を変えられ、設定画面にも反映される |
| A-20 | 3デッキ以上で始めるとおすすめが出て、1・2デッキを選べる。「次回以降表示しない」にすると、次から出ない |
| A-21 | ログインボーナスは1日1回だけ受け取れる。交換の計算が 1チップ = 20 で合っている。ブラウザを開き直しても、チップと所持金が残っている。チップがなくなると換金画面に移り、所持金もなければ「とほほ…」が出る |
| A-22 | トップから説明を開いて5ページを読める(中学生が読んで分かる言葉になっている) |
| A-12 | 勝敗が大きく表示され、効果音が鳴る(オフにすると鳴らない) |
