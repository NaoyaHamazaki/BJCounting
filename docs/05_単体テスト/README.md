## 計画
`app/src/game/game.test.ts`(Vitest)。`game/` の関数を対象にする。

| 対象 | 確認すること |
|---|---|
| deck | 1〜8デッキで 52×N 枚、ランクごとの枚数、id の重複なし、シャッフルで枚数が変わらない |
| count | Hi-Lo 値、1デッキ全部で RC=0、TC = RC ÷ 残りデッキ数、確率の合計100%、残り0枚のとき |
| hand | A の 11/1、BJ・ペアの判定、S17 |
| CPU の戦略 | ソフト17以下でヒット、ハード12〜16はアップカード7以上でヒット |
| チャンス | 3パターンの境界(TC 0.9/1/1.9/2)、BJ になる確率(シャッフル直後の式と一致、小さいカードが減ると上がる) |
| クイズ | 正解が選択肢に1つだけ・重複なし(各種300問)、点数・合計・確率・増減・TC の正解が正しい、モードに合った種類が出る |
| 精算 | BJ 3:2、スプリット後の 21 は 1:1、両者BJは引き分け、バースト、ディーラーのバースト、同点、ディーラーBJ |
