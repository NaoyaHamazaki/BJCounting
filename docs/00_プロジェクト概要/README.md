## プロジェクト
- **名前**:確率ラボ21(トランプで学ぶ確率とカウント)プロトタイプ。2026-11-15 に「Blackjack Count Trainer」から改名(99を参照)
- **目的**:小中学生でも分かる「確率の勉強」として、ブラックジャック形式のゲームでカードカウンティング(Hi-Lo)を体験できるWebアプリ。残りカードの構成と出現確率を可視化し、「なぜカウントが高いと有利なのか」を目で見て納得できるようにする。
- **原典**:プロジェクト直下の `企画.txt`(要件定義書 V2)

## 用語集
| 用語 | 意味 |
|---|---|
| シュー | 未使用カードを入れて配る箱 |
| ディスカードトレイ | 使用済みカードを置くトレイ |
| ランニングカウント(RC) | 出たカードの Hi-Lo 値の合計 |
| トゥルーカウント(TC) | RC ÷ 残りデッキ数。プラスが大きいほどプレイヤー有利 |
| Hi-Lo | 2〜6 を +1、7〜9 を 0、10〜A を -1 と数える方式 |
| ペネトレーション / カットカード | シューの何%を配ったらシャッフルするか。本アプリは 75% |
| S17 | ディーラーはソフト17を含む17以上で止まるルール |
| ホールカード | ディーラーの伏せたカード |
