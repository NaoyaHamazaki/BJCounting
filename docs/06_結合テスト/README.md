## 計画
`app/src/store/useGameStore.test.ts`(Vitest)。シューに決まった順のカードを積み、ストアの操作を通して確認する。観点は [03_詳細設計](../03_詳細設計/README.md) から。

| ケース | 確認すること |
|---|---|
| 配札 | 4枚配り、ホールカードは数えない。見えていない枚数が 49 |
| スタンド → ディーラー | S17 まで引いて精算。RC = 出たカードの合計 |
| プレイヤーBJ | 即精算で 3:2、ホールカードが開く |
| インシュランス | ディーラーBJ のとき 2:1 で払われ、差し引き0 |
| ダブル | 賭け金2倍、1枚だけ受け取り、勝ちで +100 |
| スプリット | 2ハンドに分かれ、それぞれ1枚追加、チップが2倍かかる |
| シャッフル | 75%超で、シュー52枚、RC=0、seen=0 |
| リセット | チップ・ベット・シューが初期状態 |
| CPU の配札順 | 右CPU → 自分 → 左CPU → ディーラー で2周。CPU のカードも RC に入る |
| CPU 込みの1ラウンド | 最後まで自動で進み、全員が精算され、RC = 出たカードの合計 |
| CPU の人数変更 | 席が作り直される |
| 解説用の記録 | 表になったカードだけが、誰のカードかと引く前の状態つきで記録される。ホールカードは開いたときに記録 |
| ラウンド途中の設定変更 | 賭けたチップが戻り、ベットの段階に戻る |
